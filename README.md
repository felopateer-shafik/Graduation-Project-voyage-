# Voyage – All-in-One Travel Ecosystem

## Overview

Voyage is a graduation project developed at Misr University for Science and Technology (MUST). It is a unified travel booking and management platform that combines flight bookings, hotel reservations, tour ticketing, travel packages, AI-powered trip planning, loyalty rewards, and customer support into a single web application.

The platform aims to solve the fragmentation problem in modern travel planning by providing a centralized ecosystem for travelers.

## Key Features

### ✈️ Unified Booking Engine

* Flight booking
* Hotel reservation
* Tour booking
* Travel package purchasing
* Unified booking history

### 💰 Price Freeze

* Lock a quoted price for 24 hours
* Protect users from price fluctuations
* Simple freeze fee mechanism

### 🤖 AI-Powered Trip Planner

* Powered by Google Gemini 2.5 Pro
* Retrieval-Augmented Generation (RAG)
* Generates personalized travel itineraries
* Recommendations based on real platform inventory

### 🎯 AI Customer Support

* Natural language assistance
* FAQ-based responses
* Personalized support using booking history

### 🏆 Loyalty Rewards Program

* Bronze, Silver, Gold, and Platinum tiers
* Earn 1 point per $1 spent
* Redeem points for wallet credits
* Full transaction audit trail

### ⭐ Reviews & Ratings

* Booking-verified reviews
* Fraud prevention through booking validation

### 🌍 Destination Discovery

* Countries, cities, and landmarks
* Interactive map integration
* Travel exploration tools

### 🕶️ AR Hotel Preview

* 3D hotel room visualization
* Built using Three.js
